A product education library should help a user complete a real task. Start with the moment where users get stuck, then make the shortest useful lesson for that moment. A long list of feature tours can wait.

## Start with the user's first useful outcome

Map the path from signup to the first result a customer cares about. Ask support and customer success teams which steps repeatedly need explanation. Review onboarding questions and product analytics if you have them.

For each lesson, write one outcome: “After this video, the viewer can connect a source and see their first report.” That makes the script easier to scope and gives you a way to judge whether the lesson worked.

## Separate foundations from role-specific workflows

Most products need a short foundation: setup, navigation, core concepts, and the first successful action. Beyond that, users often need different paths. A marketer and a finance lead may use the same product for different jobs.

Organise those deeper tutorials by task or role, not only by feature name. A viewer looking for a result should be able to find the relevant lesson without knowing your internal product terminology.

## Keep each video focused

Show one workflow at a time. Introduce the problem, demonstrate the action in the actual product, and end with the result and next step. Use motion or annotation to direct attention to the control that matters. Avoid zooms and decoration that make the interface harder to follow.

If a workflow needs several prerequisites, link to the foundation lessons instead of repeating a long setup in every video.

## Plan for product changes

Before production, identify screens that change frequently. Keep those shots modular so you can replace one section without rebuilding the whole lesson. Store scripts, source files, captions, and a list of the product version shown in each video.

Assign an owner for review after major releases. An accurate short library is more useful than a large library with outdated interfaces.

## Put lessons where users need them

The library page is one destination. The same lesson can also help inside onboarding emails, help articles, in-product guidance, and customer success conversations. Use a title that describes the task so it works in each context.

To choose the next video, look for repeated support questions, drop-off points, and searches with no useful answer. Those signals are stronger than an arbitrary target number of videos.
